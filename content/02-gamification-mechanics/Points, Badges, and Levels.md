# Points, Badges, and Levels

Gamification uses game inspired features to make learning more interactive. There are three common features to use and those are points, badges, and levels. When these features are used in a high-school STEM classroom, students are given a clearer picture of their progress throughout the game while learning challenging topics in science, technology, engineering, and mathematics. Students are able to work through smaller tasks and see growth along the way instead of completing a large assignment with little feedback.
